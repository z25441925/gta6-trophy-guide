VICE TRACKER is an offline companion for the 55-trophy GTA VI list. It pairs a searchable, filterable trophy tracker with a five-phase roadmap toward platinum; progress is saved in the browser and can be exported or imported. Missable flags call out trophies with conditions that can be failed, while spoiler mode hides unearned story details. The guide and its hand-drawn Vice City-inspired interface run locally without a network connection or build step.

## Run it

Run `node serve.ts`, then open http://localhost:8080.
