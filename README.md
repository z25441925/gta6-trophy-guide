VICE TRACKER is a fully offline GTA VI trophy guide and tracker. It covers all 55 official PlayStation 5 trophies with a persistent checklist (progress saved in the browser, with JSON export and import), search and filters by grade and kind, and a spoiler mode that hides unearned story trophies. A five-phase platinum roadmap orders the run and flags as MISSABLE the trophies whose own official descriptions state a condition a player can fail, each with a short "when it can be missed" note. Every trophy carries a guide written for this app from the official list, and each guide cites that list as its source. No network, no build step, no Rockstar logos or official artwork: the Vice City mood is hand-drawn CSS and SVG.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser. The app is fully static and works offline; opening app/index.html directly also works.
